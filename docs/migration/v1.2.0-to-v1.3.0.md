# v1.2.0 → v1.3.0 迁移指南

> **版本**：v1.3.0（minor，向后兼容新增功能）
> **基线版本**：v1.2.0（crates.io 已发布，31 crate）
> **日期**：2026-09-23

## 概述

v1.3.0 新增 8 个 crate + 扩展 10 个存量 crate，覆盖 18 个实施阶段（P1-P18）。所有新增功能通过 Cargo feature gate 控制，默认不启用，v1.2.0 pub API 保持不变。

| `sz-rust-ops-api` | 运维 API（admin guard + 灰度发布） | 默认启用 |

## 迁移步骤

### 1. 更新依赖

```toml
# Cargo.toml
[dependencies]
sz-rust-core = "1.3"
sz-rust-ai-facade = "1.3"
# ... 其他 crate 同理
```

### 2. 启用新功能（可选）

```toml
# 启用配置中心 Consul 后端
sz-rust-config-center = { version = "1.3", features = ["consul", "encryption"] }

# 启用测试工具链
sz-rust-testkit = { version = "1.3", features = ["test-utils"] }

# 启用 AI 多 Provider
sz-rust-ai-facade = { version = "1.3", features = ["all-providers"] }
```

### 3. 代码变更（无破坏性变更）

v1.3.0 所有新增 API 仅追加不修改，v1.2.0 代码无需改动即可编译运行。

### 4. 配置变更

新增配置项（可选，不配置则不启用）：

```yaml
# 配置中心
config_center:
  backend: consul
  address: "127.0.0.1:8500"
  encryption: true

# 服务注册
service_registry:
  backend: nacos
  address: "127.0.0.1:8848"

# 多模型路由
ai_router:
  strategy: capability
  models:
    - name: kat-coder-pro-v2.5
      capabilities: [codegen]
      priority: 100
```

## 常见问题

### Q: 升级后编译报错？

A: v1.3.0 向后兼容，不应有编译错误。如遇到问题，检查 feature gate 是否正确配置。

### Q: 如何启用 AIGC 代码生成闭环？

A: 添加 `sz-rust-codegen-loop` 依赖，调用 `parse_requirement` + `CodegenLoop::run`。

### Q: 如何使用多模型路由？

A: 注册模型到 `ModelRegistry`，通过 `FallbackChain::route(capability, strategy)` 路由。
