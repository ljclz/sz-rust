# ADR-047：审计链落库改为有界异步缓冲重放（消除慢库对业务延迟的影响）

- 状态：已接受
- 日期：2026-10-30
- 决策者：SZ-Rust Team（性能整改现场验证 + 合规决策）
- 相关验证：`docs/audit/2026-10-29-性能整改现场验证记录.md`（§5 审计丢弃发现）
- 决策来源：现场验证发现 `v18-audit-chain` 在 c=50 负载下出现 397 条「审计记录落库超时（1s），已丢弃」ERROR，属合规缺陷（审计不可丢）。用户于 2026-10-30 选择「本地缓冲重放」方案。

## 背景

`v18-audit-chain` 中间件对 POST/PUT/DELETE（排除 /health /metrics /api-docs）记录链式哈希审计，
并同步写入 `operate_log`。旧实现每条记录在请求路径内同步等待数据库写入，最长 1 s：
- 慢库/连接池争用时，单条写入超时即丢弃（fail-open），审计记录静默丢失；
- 请求延迟被审计写库拖累（每写请求最多额外等 1 s）。

现场真库压测中实测到 397 条 ERROR「审计记录落库超时（1s），已丢弃」（记录 §5），
且复测轮为 0 条 —— 触发与负载/时序相关而非常年必现，但「审计不可丢」的合规诉求要求结构性修复。

## 决策

将审计落库从「请求内同步写库」改为「有界异步缓冲重放」：

1. **请求路径只投递，不等待**：中间件把审计记录投递到有界 `mpsc` 通道（`AUDIT_BUFFER_CAPACITY = 10_000`）后立即返回，业务延迟与数据库写入完全解耦。
2. **后台任务重试落库**：`spawn_audit_worker` 消费通道并写入 `operate_log`；失败按 `AUDIT_RETRY_DELAY = 500 ms` 重试，超过 `AUDIT_MAX_RETRIES = 5` 后丢弃并计数。
3. **有界 + 丢弃计数可观测**：通道满（数据库持续不可写）时新记录丢弃并计数；丢弃计数暴露为
   - Prometheus Counter `sz300_audit_dropped_total`（`/metrics`），
   - [`AuditSink::dropped_count`]（程序内可读）。
4. **单次写入仍有 1 s 超时**：`persist_record` 保留 `PERSIST_TIMEOUT = 1 s`，超时视为该次尝试失败，交由重试逻辑处理（而非直接丢弃）。
5. **测试/降级路径**：`spawn_audit_drain` 丢弃所有记录（保持通道畅通），供集成测试与 bench 使用，避免噪音。

**接线**：`AppState` 新增 `audit_sink: Arc<AuditSink>`；`main.rs` 注册丢弃计数器并启动后台 worker；`router.rs` 以 `(chain_auditor, Some(audit_sink))` 二元组状态挂载中间件。

## 代价

- **内存上界**：缓冲最多 10_000 条；数据库长时间不可写时，超出部分的审计记录仍会丢失（但有计数与指标，可告警）。
- **审计实时性下降**：记录不再在请求返回前落库，而是在后台任务中落库（通常毫秒级，故障时最多延迟到重试上限）。
- **pub API 增加**：`AuditSink` / `AuditJob` / `spawn_audit_worker` / `spawn_audit_drain` 成为公开 API（均已带文档注释）。

## 验证

- `cargo test -p sz-rust-sz300 --lib` = **109 passed / 0 failed**（新增 3 个 `AuditSink` 单测：投递到接收端 / 通道关闭计丢弃 / Prometheus Counter 同步递增）。
- `cargo test -p sz-rust-sz300 --test audit_chain_test` = **9 passed / 0 failed**（中间件在 `sink=None` 时仅维护内存链，行为不变）。
- `cargo clippy -p sz-rust-sz300 --all-targets -- -D warnings` = **0 warning**。
- **真库端到端**（一次性 MySQL 9.6 + migrations + debug 二进制 + 门禁短跑）：453 个业务 POST → `operate_log` **453 行**（0 丢弃），服务日志无「审计缓冲已满或重试耗尽」错误。

## Bug 定位提示

- 缓冲与重试：`packages/sz-rust-sz300/src/middleware/audit_chain.rs`（`AuditSink` / `AuditJob` / `spawn_audit_worker` / `AUDIT_BUFFER_CAPACITY` / `AUDIT_MAX_RETRIES` / `AUDIT_RETRY_DELAY`）
- 丢弃指标：`main.rs`（`sz300_audit_dropped_total`）
- 中间件接线：`packages/sz-rust-sz300/src/router.rs`（`from_fn_with_state((chain_auditor, Some(audit_sink)), ...)`）
