# ADR-045：数据归属过滤与令牌生命周期安全加固

- 状态：已接受
- 日期：2026-10-28
- 决策者：SZ-Rust Team（AppSec 评测整改）
- 相关评测：`docs/audit/appsec-eval-prompt.md`（10 维评分 5.2/10）
- 整改报告：`docs/audit/2026-10-28-appsec-remediation.md`

## 背景

AppSec 只读评测发现以下高危问题：

1. **IDOR/水平越权**：`merchant/product/order/device` 的 list/info 端点无数据归属过滤，任意登录用户可读取其他商户数据；写端点同样未校验归属。
2. **认证会话桩实现**：`/api/v1/auth/refresh` 与 `/api/v1/auth/logout` 为桩（不轮换、不吊销）。
3. **WS/SSE 未认证**：`/ws` 与 `/events` 在公开白名单且无连接认证。
4. **key-rotation 非密码学安全 RNG**：JWT 轮换密钥由时间种子 LCG 生成，可被预测。

## 决策

### 1. 数据归属过滤（CurrentUser 上下文）

- 在 `auth_middleware` 中新增 `CurrentUser` 请求扩展（`user_id / username / merchant_id / is_admin`），JWT 校验通过后经 `try_get_user_info_by_id`（非 panic，DB 未初始化时降级为 None）注入。
- `controllers/common.rs` 提供 `effective_merchant_scope_*` 与 `can_access_merchant_resource_*` 辅助函数。
- 业务端点规则：非管理员 list 强制 `merchant_id = 当前用户`；info/update/delete/bind/unbind/OTA 校验资源归属；create 强制归属当前商户。管理员放行全部。
- 权衡：每次请求增加一次 DB 查询（获取 merchant_id）。示例应用可接受；高并发场景可将 merchant_id 加入 JWT claims（需 sz-orm 支持自定义 claim）或引入缓存。

### 2. 令牌生命周期（refresh 轮换 + logout 黑名单）

- `refresh`：调用 sz-orm `JwtAuthenticator::refresh_token`（严格校验 `token_use=refresh`，防类型混淆），换发新 access token。
- `logout`：服务端内存黑名单（SHA-256 哈希存储 + 过期惰性清理）；`verify_token` 与 `verify_token_with_audience` 均检查黑名单。
- 权衡：进程内存黑名单仅适用于单实例部署；多实例需替换为 Redis 等共享存储（已记录于整改报告遗留事项）。

### 3. WS/SSE 强制 JWT

- `/ws`、`/events` 在升级/订阅前校验 `Authorization: Bearer` 或 `?token=` 查询参数，无效返回 401。

### 4. key-rotation 使用 CSPRNG

- `RandomKeyGenerator` 由时间种子 LCG 改为 `rand::rngs::OsRng`（操作系统 CSPRNG）。

## 影响

- 行为变化：非管理员用户的 list 结果将只包含自己商户的数据；越权访问返回 403；logout 后旧 token 立即失效；refresh 需携带 refresh_token。
- 默认 features：`v18-security-headers / v18-data-mask / v18-audit-chain / v18-key-rotation / v19-jwt-audience` 默认启用（原 `default=[]`）。
- 验证：`cargo test -p sz-rust-sz300 --lib` = 87 passed / 0 failed（含 26 项 security_gauntlet）；`cargo test -p sz-rust-key-rotation` = 8 passed；clippy `-D warnings` = 0 warning；link-check / doc-code-consistency 门禁通过。

## Bug 定位提示

- IDOR 归属过滤入口：`packages/sz-rust-sz300/src/controllers/common.rs`（`effective_merchant_scope_*` / `can_access_merchant_resource_*`）
- 用户上下文注入：`packages/sz-rust-sz300/src/middleware/auth_middleware.rs`（`CurrentUser` / `run_with_user_context`）
- 令牌黑名单/轮换：`packages/sz-rust-sz300/src/services/auth_service.rs`（`revoke_token` / `is_token_revoked` / `refresh_access_token`）
- WS/SSE 校验：`packages/sz-rust-sz300/src/router.rs`（`extract_bearer_token`）
- CSPRNG：`packages/sz-rust-key-rotation/src/manager.rs`（`RandomKeyGenerator`）
