## 六、对抗性边界审查

### ✅ Critical — 远程 DoS（v7.0 已修复）

**BUG-001: pgwire 负长度 panic**（已修复）
- 文件：message.rs:475
- 根因：i32 as usize 负值→usize::MAX→溢出→split_to panic
- 攻击：发送 b'Q'+0xFFFFFFFF
- 修复：改用 u32::from_be_bytes 解析长度，length < 4 返回 InvalidData
- 回归测试：adversarial_net.rs `test_adv_net_001e_negative_length_message` ✅

**BUG-002: pgwire Bind 负 param_count panic**（已修复）
- 文件：message.rs:531,591
- 根因：i16 as usize→Vec::with_capacity(usize::MAX) panic
- 修复：改用 u16::from_be_bytes + MAX_BIND_PARAMS=65535 上限校验（Parse + Bind）
- 回归测试：adversarial_net.rs `test_adv_net_001f_negative_bind_param_count` ✅
