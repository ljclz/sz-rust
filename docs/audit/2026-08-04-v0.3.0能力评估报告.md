### 生产 unwrap() 分布（Top 5）

| 文件 | 数量 | 说明 |

> **铁律 2 合规性**：133 处生产 unwrap 均为启动时初始化或内部不变量断言，无运行时 I/O 路径上的裸 unwrap。`scripts/check-unwrap.py` 可作为 pre-commit 门禁。

### unsafe 块说明

3 处 unsafe 均在 `hot_reload.rs`，用于 `libloading::Library` 的 FFI 调用（动态加载 addon .dll/.so）：
```rust
unsafe { Library::new(path) }?;                          // line 277
unsafe { library.get(b"addon_init\0") }                  // line 282
unsafe { init_symbol() }                                 // line 289
```
属必要 FFI，无替代方案。ADR-016 已记录风险评估。
