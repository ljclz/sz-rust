## 四、同类产品对比

### vs Axum / Actix-web（Rust 原生框架）

- **对方优势**：社区生态（crates.io 中间件、招聘、问答）、极简心智、零学习负担。
- **sz-rust 优势**："全家桶开箱即用"——Laravel 式 ORM/迁移/鉴权/插件/AI，Axum 用户要自己攒半年。
- **关键命题**：Axum 是免费共识，sz-rust 必须回答"为什么不直接用 Axum"——答案只能是行业插件 + AI 生成，而非框架本身。

### vs Laravel / ThinkPHP（目标迁移来源）

- **sz-rust 优势（碾压性）**：内存 17.3MB vs 数百 MB；无 GC 抖动；编译期安全；启动速度。
- **对方优势（碾压性）**：Eloquent 生态、14000+ 包、部署便利度、开发者供给、文档教程量。
- **结论**：迁移工具（P1-1）不存在，则性能对比永远停留在纸面——客户没有低成本迁移路径。

### vs Go-Gin / goframe（最近竞位）

- **对方优势**：单二进制部署、协程心智简单、人才池大。
- **sz-rust 优势**：类型系统 + 宏能力使 AI 生成代码获得编译期验证（生成质量上限更高）；ORM 对齐 PHP 心智（迁移学习成本更低）。

### 独特定位

目前没有任何框架把 **"Rust 性能 + Laravel 开发体验 + AI-native 生成 + 插件市场商业模式"** 四件事放在一个篮子里。蓝海是真的，但 SDD Agent（P0-2）和插件互通（P0-4）不做完，就游不过去。

## 五、建议的下一步优先级（后续开发按此推进）

1. **覆盖率结构性短板专项**（业务层单测）—— ✅ phase1 已完成 8.7% → 85.85%（commit 4603523，2026-09-04）；phase2 目标 ≥90% 待 Docker 度量。报告建议的 30%→60%→85% 分阶段目标已超额达成。
2. **P0-3 开源/企业版分离**——商业化前置条件，越晚做重构成本越高。产出：workspace 拆分方案 + 独立发布流程。
3. **P0-4 插件数据互通最小闭环**——CRM/CMS 共享用户表即可演示。这是 demo 里最能打动客户的一项。
4. **P0-2 SDD Agent**——成本最高、风险最大，等 2/3 验证商业假设后再投入。
5. P1 迁移工具/模板库/行业 RAG——随客户接触反馈排期。
