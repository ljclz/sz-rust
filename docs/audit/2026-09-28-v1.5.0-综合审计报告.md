## 3. 安全审计

### 3.1 内存安全

- **unsafe 使用**：0 处
  - v1.5.0 新增 3 个 crate 声明 `#![forbid(unsafe_code)]`：`auto_rollback.rs`、`migration_enhanced.rs`、`leak_detector.rs`
  - workspace 级 `#![forbid(unsafe_code)]` 继承
  - 证据：`git diff v1.4.0..HEAD -- packages/ | grep "^+.*unsafe"` 仅匹配 forbid 声明和 quality_scorer 的 unsafe 检测逻辑

### 3.2 注入防护

- **SQL 拼接**：6 处，全部安全
  - `migration_enhanced.rs` GET_LOCK/RELEASE_LOCK：使用 `Self::LOCK_NAME` 常量（"sz_rust_migration_lock"）
  - `migration_enhanced.rs` pg_advisory_unlock：使用 `Self::LOCK_KEY_PG` 常量
  - `migration_enhanced.rs` SELECT version/checksum：使用 `self.table_name` 配置参数（默认 "__migrations"）
  - 无用户输入直接拼接 SQL

### 3.3 敏感信息

- **硬编码密码/密钥**：0 处
  - 测试连接字符串中的密码仅在 `#[ignore]` 集成测试中，不进入生产二进制
  - `#[serde(skip_serializing)]` 脱敏约束由 workspace 规则强制

### 3.4 错误处理

- **生产代码 unwrap/expect**：0 处
  - 所有 unwrap 仅在 `#[cfg(test)]` 模块中
  - 生产路径统一 `Result<T, E>` 错误传播

- **panic/todo/unimplemented**：0 处（生产代码）
  - 匹配到的 panic 均在测试断言中
