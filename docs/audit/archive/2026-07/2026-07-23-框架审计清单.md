### 2.2 sz-orm 外部依赖 CI 检出问题（已修复）

**原问题**：sz-rust 的 [Cargo.toml:103-121](../../Cargo.toml#L103-L121) 通过 `path = "../sz-orm/packages/..."` 引用外部依赖 sz-orm，但 GitHub Actions 默认只检出当前仓库，导致 8 个 CI job 全部失败。

**修复方式**：所有 workflow 中原 `Check sz-orm dependency`（检查目录存在性，不存在则 exit 1）步骤替换为：
```yaml
- name: Checkout sz-orm dependency
  run: git clone https://github.com/ljclz/sz-orm.git ../sz-orm
```

**受影响 job 及修复状态**：
- ci.yml: test / doc / feature-matrix / unused-deps → ✅ 已修复
- soak.yml: soak / soak-smoke → ✅ 已修复
