### 3.2 失败测试根因分析

**vectorize.rs:474 `cold_start_with_existing_journal_skips`**：
- 测试逻辑（vectorize.rs:455-475）：第一次 cold_start 成功 vectorize（first.success > 0），第二次 cold_start 应跳过已 vectorize 的文件（second.skipped > 0, second.success == 0）。
- workspace 全量跑实测：second.success == 1（仍有 1 个成功），`assert_eq!(second.success, 0)` 失败。
- **红队独立复跑**：`cargo test -p sz-rust-rag --lib` 得 **104 passed; 0 failed**（失败无法独立复现）。
- 根因：测试 vectorize.rs:458 用 `env!("CARGO_MANIFEST_DIR").parent().parent()` 即仓库根目录作为 workspace，扫描所有 .rs 文件，workspace 全量跑时受其他测试干扰导致 flaky。
- 影响范围：sz-rust-rag crate 的 vectorize 模块，影响 RAG 向量化冷启动幂等性（仅 workspace 全量跑时 flaky，单独跑通过）。
- 严重性：**P1 级**——flaky test 隔离缺陷，非发布阻塞项。CI 中 ci.yml:125 `cargo nextest run --workspace --all-targets --retries 2` 会重试 2 次，且 nextest 测试隔离优于 cargo test，CI 中可能不失败。建议：改用 `CARGO_MANIFEST_DIR` 自身或 test fixture 隔离。
