## 4. 优点清单（附证据）

1. **参数化 SQL 纪律**：sz300 全走 `?` + params，`query_as!` 零使用，raw query 均为静态常量 SQL（graphql/schema.rs:361,387,413）。
2. **安全 gauntlet 刁钻**：26 项覆盖 method-override、Host 头注入、X-Forwarded 伪造、Content-Type 混淆、路径归一化变体（security_gauntlet_tests.rs:215-359）。
3. **上传安全闭环**：5MB + 白名单 + 服务端重命名（时间戳_uuid.ext）+ delete canonicalize 前缀校验（file_service.rs:9-10,46-51,81-93）。
4. **密钥治理**：生产代码零硬编码密钥；JWT secret 缺失 panic；Debug 脱敏有 gauntlet 锁定（config.rs:46,74 + gauntlet :443,463）。
5. **供应链配置成熟**：deny.toml 22 条带理由 ignore + 许可证白名单 + `[sources]` 强制 crates.io。
6. **工程化防幻影体系**：21 审计脚本 + doc-debt 全 RESOLVED + CI 十 job（cargo-hack、cargo-deny、audit）。
7. **启动工程化**：优雅关停（main.rs:295-326）、metrics token 可选鉴权、RBAC 路由分层（router.rs:320-365）。

## 5. 缺陷清单（按优先级）

- **P0-1（已修复）公开免鉴权 WASM 执行端点无资源限制 = 远程 DoS + tokio worker 永久阻塞**

## 6. 跨语言对比表

| 维度 | sz-rust | ThinkPHP 8 | ASP.NET Core |
|---|---|---|---|
| 性能模型 | 常驻 + async tokio + serde；CPU 型任务已隔离（WASM spawn_blocking） | FPM 每请求重建框架；swoole 常驻但割裂 | Kestrel 常驻 + 编译期强类型管道 |

| 部署 | distroless 容器就绪；宝塔靠 80+ SSH 脚本堆 | 宝塔原生一等公民 | IIS/K8s 成熟 |
| 团队成本 | Rust 陡峭；API 对齐 PHP 降低迁移摩擦 | 目标受众母语 | C# 团队即插即用 |

## 7. 生产就绪度结论

**基本就绪但有关键缺口。** 后端单体（MySQL/PG）在密钥管理、注入防护、优雅关停、可观测性、CI 门禁上达到可部署水准（141 测试 + clippy 零告警实测）。缺口：① 前端层不存在（admin-ui 等为 headless 库，无真实管理界面）；② server 级内存基线未落地；③ 多库（Oracle/MSSQL）连通未实测。P0-1 已修复后，「就绪」的障碍主要在前端与容量验证。
