## 4. 优点清单（附证据）

1. **P0-1 插件真实验签已闭环**：`plugin_manager.rs:200-231` 用 `ed25519-dalek` `VerifyingKey::from_bytes` + `public_key.verify(&package, &signature)`，Base64 解码公钥/签名/包任一步失败 fail-closed（return false）；负例测试 `test_install_forged_64byte_signature_rejected`（:332）+ `test_install_invalid_public_key_rejected`（:346）。
2. **P1-2 默认安全 features 已闭环**：`Cargo.toml:100-109` default 含 v18-security-headers/v18-data-mask/v18-audit-chain/v18-key-rotation/v19-jwt-audience/v19-saga。v19-plugin-flow 有意不进 default（最小攻击面，验签负例由 ci.yml gated-security-tests job 显式跑）。
3. **P1-3 /metrics fail-closed 已闭环**：`main.rs:142-163` 未配置 token 时默认拒绝，需显式 SZ300_METRICS_PUBLIC=true 才公开；生产环境无 token 无公开则 `anyhow::bail!` 启动失败。`health.rs:202-227` is_metrics_token_valid + constant_time_eq（常量时间比较防时序）+ 专项测试 `test_no_token_fail_closed_by_default`（:234）。
4. **P1-5 refresh/logout 已闭环**：`auth_service.rs:25` TOKEN_BLACKLIST（OnceLock<Mutex<HashMap>>），`:32` revoke_token（SHA-256 哈希存储+惰性清理过期条目），`:44` is_token_revoked（O(1) 查找），`:549` verify_token 检查黑名单，`:565` refresh_access_token 检查黑名单+调用 sz-orm JwtAuthenticator::refresh_token（校验 token_use=refresh）。
5. **P1-6 CORS 生产 fail-closed**：`router.rs:65-91` cors_layer_from_env：配置 SZ300_CORS_ORIGIN → 精确 origin；生产未配置 → `CorsLayer::new()`（空，拒绝所有跨域）+ error 日志；非生产未配置 → 回退 `*`。
6. **IDOR/水平越权已修复**：service 层 merchant_id 归属过滤（`merchant_service.rs:45/67-68` 注释"2026-10-28 IDOR 修复"+`WHERE merchant_id = ?`、`device_service.rs:300-301` `WHERE device_id = ? AND merchant_id = ?`、`product_service.rs:75-76` `merchant_id = ?`、`order_service.rs:124-125` `merchant_id = ?`）；非管理员强制归属当前商户，管理员放行（整改报告 §3）。`rbac/guard.rs:69-82` 是 RBAC 角色指派修复（2026-11-05 staging F-3），非 IDOR。
7. **WS/SSE 强制 JWT 校验**：`router.rs:548-556` ws_handler 升级前校验 JWT（Authorization 头或 ?token=），无效返回 401；`:634-638` sse_handler 订阅前校验 JWT。
8. **WASM 移出公开白名单**：`router.rs:40-43` 注释说明原公开条目移除原因（公开+无燃料=DoS），现由 auth_middleware 保护。
9. **供应链 review-by 过期机制**：`deny.toml:13-15` 每条 ignore 行尾带 `# review-by=YYYY-MM-DD`，由 `scripts/audit/advisory-ignore-expiry.py` 在 CI 中校验，过期即失败，强制定期复审。
10. **gauntlet 实测通过**：26 passed / 0 failed / 0 ignored，5.02s（隔离环境 D:\rust-target-verify，见 §9）。
11. **gated-security-tests CI job**：`ci.yml:131-144` 显式跑 `cargo test -p sz-rust-sz300 --features v19-plugin-flow --lib -- services::plugin_manager`，确保插件验签负例在 CI 中执行。
12. **unsafe 治理维持**：sz300 `#![forbid(unsafe_code)]`（lib.rs:20, main.rs:5），workspace `unsafe_code = "forbid"`（Cargo.toml:121），仅 4 处 `#![allow]` 与基线一致（core/alloc_counter.rs:39, core/mem_pool.rs:24, core/runtime/hot_reload.rs:85, router-facade/simd_str.rs:22），无新增 unsafe。
