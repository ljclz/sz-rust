## 二、高危漏洞详情

### H-1 水平越权（IDOR）——全业务 CRUD 无身份绑定

**根因链**：
1. `auth_middleware.rs:50` 验证 JWT 后**丢弃用户身份**（`Ok(_user) => next.run(req)`），未注入请求上下文
2. `role_guard.rs:61-66` 同样丢弃 `user`，仅做角色判断
3. 所有业务 handler 从**请求体**取 `merchant_id`/`order_id`/`user_id`，无归属校验

**攻击场景**：任意登录用户 `POST /api/v1/order/list {"merchant_id": 1}` 即可查询商户 1 的全部订单；`order/info {"order_id": 任意}` 读取任意订单详情（含订单项）。**全租户数据横向泄露**。

**修复方案**：
- 中间件将 JWT claims（user_id/merchant_id/role）注入 `Request.extensions()`
- 业务层强制用身份值覆盖/校验请求体中的租户字段（服务端身份优先原则）

### H-2 请求体无大小限制 → OOM DoS

**位置**：`http-facade/src/request.rs:75-77`

```rust
let bytes = body.collect().await...to_bytes();  // 无限读取
```

所有 POST 端点（登录/订单/上传/CSRF 写路径）都经此函数。攻击者发送 GB 级 body → 单请求 OOM。axum 提供 `to_bytes(req, limit)` 或 `DefaultBodyLimit`，当前未启用。

**修复方案**：`fetch_post_data` 增加上限（如 1MB），router 层加 `DefaultBodyLimit`。

## 三、中危漏洞详情

### M-1 AI 端点提示注入 + 成本攻击
`model` 参数用户可控（可指定任意 model）、`prompt` 无长度上限、无独立限流。攻击者可刷 `prompt` 长度耗尽 LLM 预算（经济型 DoS）。
**修复**：model 白名单、prompt 长度上限（如 4K tokens）、按用户/IP 单独限流。

### M-2 限流绕过：X-Forwarded-For 直接可信
`extract_client_ip` 直接取 `X-Forwarded-For` 首项。若服务直连公网（无反向代理重写头），攻击者可伪造该头**无限绕过 IP 限流**（配合 H-2 放大）。
**修复**：仅信任代理链（`from_env` 配置可信代理），或默认用 socket 对端地址。

### M-3 JWT 密钥无强度校验
`validate_jwt_config` 只查存在性。HS256 对称密钥，弱密钥可被离线暴力破解后**伪造任意用户 token**。
**修复**：启动时校验长度 ≥ 32 字节 + 熵。

### M-4 上传无内容校验（magic bytes）
扩展名白名单不校验文件内容。虽静态服务以 `image/*` 返回（XSS 风险低），但存储的恶意文件可被其他途径利用。
**修复**：校验文件头 magic bytes 与扩展名一致。

## 四、低危漏洞详情

- **L-1**：MQTT 面无设备认证（device_sn 取自 topic，无签名校验）→ 数据污染面
- **L-2**：refresh token 响应明文返回，客户端自行存储 → XSS 后可窃全 token
- **L-3**：sz300 自研 `auth_middleware` 仅认 `"Bearer "` 前缀（核心库已做大小写不敏感，未复用）

## 六、修复优先级

1. **H-1 越权**（阻断级）：中间件注入身份 + 业务层服务端身份覆盖
2. **H-2 body 限制**（阻断级）：`DefaultBodyLimit` + `fetch_post_data` 上限
3. **M-2 IP 伪造**（高）：限流仅信代理头需配置化
4. **M-1/M-3/M-4**（中）：AI 白名单、密钥强度、magic bytes
5. L-1/L-2/L-3（低）：MQTT 认证、cookie 存储、Bearer 兼容

## 七、复现验证命令

```bash
# H-1 越权（需登录后）
curl -X POST http://127.0.0.1:8300/api/v1/order/list \
  -H "Authorization: Bearer <任意用户token>" \
  -d '{"merchant_id": 1}'   # 任意商户数据可查

# H-2 OOM（危险，勿在生产执行）
curl -X POST http://127.0.0.1:8300/api/v1/order/list \
  -d "$(head -c 1073741824 /dev/zero | tr '\0' 'a')"  # 1GB body
```
