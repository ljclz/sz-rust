### ⚠️ 严重问题:`cargo test --workspace` 整体编译失败

逐包 `--package` 可通过(4,494 lib 测试 0 失败),但 `cargo test --workspace` **编译失败**,根因经 `cargo test --workspace --no-run` 诊断:

```
error: cannot find attribute `test` in this scope
error: cannot find macro `assert_eq` in this scope
error: could not compile `sz-rust-addons-crm` (lib test)
error: could not compile `sz-rust-core` (test "validate") due to 133 previous errors
error: could not compile `sz-rust-examples` (bin "blog_demo" test)
error: could not compile `sz-rust-facade-tests` (test "end_to_end_flow")
...
```

涉及包:sz-rust-addons-crm/ecommerce、sz-rust-core 的 validate/backward_compat/fuzz/upload_parity 测试、sz-rust-examples 的 blog_demo/ecommerce_demo/quick_start、sz-rust-facade-tests 的 end_to_end_flow。

**性质判定**:这是 feature 组合/测试 target 之间的 rlib 不可用问题(`rand_chacha`/`sz_orm_mqtt`/`zlib_rs`/`tower_http` 等在 workspace 联编时找不到 rlib 格式),非业务逻辑失败。逐包单跑能过,说明业务测试本身正确。但**生产部署是整体联编,这一编译失败直接影响"可生产"判定**。

## 八、生产差距(按真实优先级)

### P0 — 阻塞级(不解决不能谈生产)

1. **`cargo test --workspace` 编译失败** — 整体联编不过,生产部署第一道关就挂。根因:测试 target 间 rlib 格式不可用 + 部分 examples 的 feature 组合缺陷。**必须先修这个,否则一切无从谈起。**
2. **cargo-audit 真实 unmaintained 依赖未处理** — paste/rustls-pemfile/ttf-parser 真实编译进产物,既有报告误判为幻影。需替换或 pin 到维护分支。
3. **无真实生产运行** — 无线上流量、无 soak 执行记录、无故障演练。

### P1 — 高影响

4. **sz-protocol 护城河不存在** — Cargo.toml 无引用、目录空。既有报告把不存在的协议栈当护城河宣传,需要么实现要么撤回声称。
5. **sz-orm-dtx 未实现** — 318 LOC 全是 tests/,无 src/。分布式事务是 Roadmap,非现状。
6. **3 个 addons 空壳** — crm/erp/ecommerce 无测试无实质,算入"全栈"是水分。
7. **限流/熔断本仓未落地** — 仅在 sz-orm-limit 外部包。
8. **主干包未发 crates.io** — 26 个 sz-rust-* 全 workspace 内部 path 引用。
9. **无横向性能对比** — 基线不可复现 + 无 axum/actix 对照。

### P2 — 中等

10. 外部使用者 0 / 无社区
11. 文档中文为主,无英文 API 参考
12. 无 loom 并发交错验证
