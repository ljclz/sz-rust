### 6.2 本次治理内容

- **真实凭据清零**：本地部署/临时脚本（SSH 密码、DB 密码、docker 密码）改为环境变量读取。
- **测试 mock 治理**：Rust 测试中的硬编码凭据值替换为占位符/运行时构造，**保留生产代码扫描**（mimosa 对 redact.rs/audit.rs 扫描 0 发现）。
- **脚本命令注入重构**：`execSync`/`exec` → `execFileSync`/`spawn` 参数数组 + 白名单 + `--` 分隔 + `--op=` 等号形式。
- **路径穿越加固**：`path.resolve/join` → 根目录校验 + basename 白名单；`h2.rs write_temp_pem` 通用 basename 校验。

### 6.3 依赖安全

- `deny.toml` 配置了 cargo-deny（许可证 + advisory），含 4 个 rustls-webpki 传递依赖 ignore（附理由，待上游升级后移除）。
- 本次 `cargo audit` 因网络不可用未能拉取在线 advisory DB（如实标注限制）。

### 6.4 遗留安全项（非阻断）

- mimosa git 门禁 L3 深度审计对 `h2.rs` 测试辅助函数 `write_temp_pem` 仍输出 path-traversal **告警**（测试代码写临时文件的跨函数 taint 误报），**不阻断提交**。
- `.mimosa/security-policy.json`（`forbidShell=false`）为本地配置（gitignored），未入库；新环境需执行 `mimosa policy init` 后同样调整，否则会重现 248 个策略误报。

### 8.1 架构分层

- **core**：`sz-rust-core` 聚合框架能力（路由/容器/中间件/错误/上传/二维码）。
- **facade 层**：`sz-rust-{http,cache,state,infra,auth,pay,orm,router,middleware,mvc}-facade` 渐进拆包（ADR-017/019）。
- **addons/业务**：`sz-rust-sz300`（业务应用）、`sz-rust-addons-*`（插件包）、`sz-rust-marketplace`/`plugin-sdk`/`addons-loader`。
- **平台**：`cli`、`mcp`、`macros`、`observability`、`config-center`、`service-registry`、`api-gateway`、`workflow`、`wasm`、`visual`、`ai-facade`、`rag`、`frontend-codegen` 等。

### 8.2 质量证据（本次实测）

- **clippy**：`cargo clippy --workspace --all-targets -- -D warnings` 在最近 5 次提交的 pre-commit 中全部通过（0 warning）。
- **fmt**：逐包 `cargo fmt --check` 57 包全部通过。
- **防幻影交付**：`doc-code-consistency.js` / `adr-code-consistency.js` EXIT=0。
- **测试覆盖**：核心模块（如 qr_code 94.31%、sz-rust-core 整体 96.17%）达标。

### 8.3 历史审计识别的架构待办（来源 `docs/audit/2026-08-21-综合深度审计报告.md`）

## 十、改进建议

1. **稳定性**：将 flaky 测试串行化或隔离全局注册表，消除并行偶发失败。
2. **安全闭环**：在 CI 中固化 mimosa 策略（`forbidShell=false`）与 cargo-deny 在线扫描；评估将 `.mimosa/security-policy.json` 纳入版本库以跨环境一致。
3. **性能复测**：在 release 构建下重跑 RSS/QPS 基线，更新 `docs/benchmarks/` 到当前版本。
4. **架构补齐**：实现历史审计点名的便捷 API（路由 `patch/head/options`、模板 include、路由分组链式 API）。
5. **AI 深化**：按产品路线图评估专业向量库与 RAG 重排序。
6. **文档国际化**：保持 README.en / ADR.en 与中文文档同步。
