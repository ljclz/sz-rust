## 八、关键技术决策记录

### 8.1 覆盖率测量方案

- **工具**：cargo-llvm-cov 0.8.7（跨平台，Linux CI + Windows 本地）
- **排除**：sz-orm-macros / sz-rust-macros（proc-macro，instrument-coverage 冲突）
- **分片**：4 个并行 job（P0/P1/P2/P3）+ sz300 DB 集成独立 job
- **阈值**：COVERAGE_THRESHOLD 环境变量（默认 85，commit message `[coverage-stage:S1]` → 30）
- **校验**：`per-crate-coverage.js` 分 crate 门槛 + `coverage-exemption.md` 豁免清单

### 8.2 sz300 覆盖率特殊处理

- **问题**：集成测试有栈溢出（0xc00000fd），llvm-cov `--all-targets` 崩溃
- **方案**：CI 中用 `--ignore-tests-in-target` + `-- --ignored` 分离 DB 集成测试
- **本地**：`cargo llvm-cov -p sz-rust-sz300 --lib` 仅采 lib 覆盖率

### 8.3 ai-facade 覆盖率特殊处理

- **问题**：claude/gemini 模块需 `--features all-providers` 启用
- **方案**：CI coverage-p1 job 中显式 `--features all-providers`
