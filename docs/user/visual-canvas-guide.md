# 可视化画布用户手册

> SZ-Rust 可视化画布（`sz-rust-visual`）是 Tauri 2.x 桌面应用，提供 SDD 编排可视化、Capability 管理、RAG 搜索和应用预览功能。

## 1. 启动画布

### 开发模式

```bash
cd packages/sz-rust-visual
cargo tauri dev
```

### 生产构建

```bash
# Windows
cargo tauri build --target x86_64-pc-windows-msvc

# macOS
cargo tauri build --target aarch64-apple-darwin

# Linux
cargo tauri build --target x86_64-unknown-linux-gnu
```

构建产物位于 `packages/sz-rust-visual/target/release/bundle/`。

## 2. 画布使用流程

### 2.1 输入需求

1. 打开画布应用，左侧「需求」面板显示需求输入框
2. 输入功能需求描述（如"实现用户 CRUD 管理功能"）
3. 点击「启动编排」按钮

### 2.2 SDD 编排

编排启动后，画布依次执行四个阶段：

| 阶段 | 产物 | 说明 |
|------|------|------|
| Spec | `spec.md` | 需求规格文档 |
| Design | `design.md` | 技术设计文档 |
| Task | `tasks.md` | 任务规划文档 |
| Coding | 源代码 | 代码生成产物 |

每个阶段完成后，画布暂停等待人工审查（HITL）。

### 2.3 HITL 审查

当编排进入等待审查状态时：

1. 对应面板显示阶段产物内容
2. 审查者可选择三种决定：
   - **确认通过**（Confirm）：进入下一阶段
   - **需修改**（Modify）：退回当前阶段重新生成
   - **需补充**（Supplement）：补充信息后重新生成
3. 可附加审查评论

### 2.4 实时日志

底部「日志」面板实时显示编排日志，包括：
- 阶段开始/完成事件
- 产物生成通知
- 错误信息

### 2.5 任务面板

「任务」面板以看板形式展示任务状态：
- 待执行 / 进行中 / 已完成 / 已失败
- 点击任务卡片查看详情

## 3. 预览功能

### 3.1 启动预览

1. 编排完成后，在「预览」面板选择设备类型：
   - 桌面（1280×800）
   - 平板（768×1024）
   - 手机（375×667）
2. 点击「启动预览」按钮
3. 画布启动临时 HTTP 服务并打开 WebView 窗口加载预览

### 3.2 停止预览

点击「停止预览」按钮，HTTP 服务关闭并释放端口。

### 3.3 预览异常

- 若产物未生成，预览按钮置灰
- 若预览加载失败，提示"预览不可用，请先完成编排生成产物"

## 4. Capability 管理

### 4.1 查看能力列表

「插件」面板显示已注册的 Capability 列表，包括：
- 能力名称（`mcp.` 前缀）
- 描述
- 参数 Schema

### 4.2 调用能力

选择能力后，输入参数 JSON，点击「调用」按钮执行。

### 4.3 RAG 搜索

在搜索框输入查询，画布调用 RAG 引擎检索行业知识库，返回匹配文档列表。

## 5. 插件市场

「插件」面板还提供插件市场交互：
- 搜索插件（关键词/标签）
- 安装/卸载插件
- 更新插件
- 登录市场（token 认证）

## 6. 开源版/企业版差异

| 功能 | 开源版 | 企业版 |
|------|--------|--------|
| SDD 编排 | MockSddFacade（占位） | SddFacadeImpl → Orchestrator |
| 产物生成 | 空字符串 | 真实 SDD Agent 产物 |
| 事件流 | 订阅有效但无事件 | 真实阶段事件推送 |

企业版通过 `--features enterprise` 编译，路由到企业版 SDD Agent。

## 7. 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Enter` | 提交审查（确认通过） |
| `Ctrl+R` | 重新生成当前阶段 |
| `Ctrl+P` | 启动预览 |
| `Ctrl+L` | 清空日志 |

## 8. 故障排除

### 8.1 画布无法启动

- 检查 `tauri.conf.json` 配置合法性
- 确认前端资源已构建（`cd frontend && npm run build`）

### 8.2 预览不可用

- 确认编排已完成且产物已生成
- 检查 `artifacts/{feature}/` 目录是否存在

### 8.3 RAG 搜索失败

- 确认 RAG 引擎已初始化
- 检查知识库连接配置
