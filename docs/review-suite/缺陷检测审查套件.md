## 4. 并发正确性检测（当前最大缺口）

本轮两个最重的 bug（DI TOCTOU、以及 cache TTL 语义）都是并发/时序类，而仓库**没有任何 Loom/Shuttle/TSan 基建**。建议三步走：

```bash
# ① Loom（模型检测，适合锁/原子操作小片段）—— 加 dev-dependency 后：
#    [dev-dependencies] loom = "0.7"
#    #[test] fn loom_container_construct_stack() {
#        loom::model(|| { /* 并发 make 两个依赖类型 */ });
#    }
cargo test -p sz-rust-core --release --features loom

# ② TSan（真实并发执行检测，CI 可跑）
RUSTFLAGS="-Zsanitizer=thread" cargo +nightly test -p sz-rust-core --target x86_64-unknown-linux-gnu

# ③ Shuttle（随机调度，比 Loom 快，适合业务级并发路径）
#    [dev-dependencies] shuttle = "0.7"，把 tokio::spawn 换 shuttle::spawn 跑关键路径
```

验证锚点：§1 的 `concurrent_first_resolve_no_cross_thread_false_cycle` 就是给这类工具准备的素材。

## 9. 已知遗留欠账（按风险排序，勿当作已修）

1. **sz300 十处 `SELECT *`**（`device/order/product/merchant_service.rs`）—— 需按模型字段映射显式列投影，涉及 schema 确认，单独任务。静态门禁 `select-star` 规则看护不恶化。
2. **模板渲染链 `std::fs`**（`mvc-facade/src/view.rs:757`、`layout.rs:88,173`、`inheritance.rs:156`）—— 改 tokio::fs 需要异步签名链式重构，单独任务。当前为同步渲染 API 的已知代价。
3. **StackPool（`sz-rust-core/src/mem_pool.rs`）**—— bump 分配器 `unsafe impl Sync`：`reset()` 与在途分配无跨纪元防护。当前无生产调用方（潜在地雷）。处置建议：要么补 Loom 测试 + 纪元文档，要么 `#[doc(hidden)]`/私有化。
4. **DI 单例工厂并发重复执行** —— thread_local 化后环检测正确，但两线程同时首解析同一未缓存工厂仍会各执行一次（后写者胜缓存）。要求严格一次语义的工厂需自行加锁（已在 API doc 注明）。
5. **fail-fast 全局句柄**（`sz300/services/auth_service.rs:29-40`、`orm-facade/src/jobs/queue_facade.rs:47`）—— 初始化前调用即 panic，属设计决策；改 Result 会波及 API。
6. **`facade/src/event.rs:42` `unimplemented!`** —— 导出 API 上的地雷，需实现或删除（API 变更决策）。
7. **DB 集成测试（--ignored）未纳入常规口径** —— SQL 层真实行为（含 10 处 SELECT * 的字段漂移风险）缺验证。
8. **orm-ext-facade `hooks.rs:823` SQL 拼接辅助** —— release 下仅 debug_assert 校验标识符，属危险辅助函数，建议改为运行时校验。
9. **`sz-rust-visual` 本机不可构建**（webview2-com-sys 静态库缺失）—— CI 有 windows job 覆盖，本地跳过。

## 10. 评审清单（人工审查时按序过一遍）

来自本轮实证的"最有产出"审查角度：

- [ ] 信任边界：MCP/HTTP 入口的所有 `args.get(...)` 是否过 `tool_guard` 或等价校验后才触达 fs / 子进程 / SQL？
- [ ] 路径拼接：所有 `root.join(变量)` 是否有词法校验或 canonicalize 前缀检查？（范本：`sz300/file_service.rs:76-103`、`marketplace/storage.rs`）
- [ ] 锁的 panic 面锁内是否执行用户代码？`expect` 是否可能中毒级联？
- [ ] 窄化转换：外部输入 → 小整数是否 clamp？
- [ ] TTL/时间语义：有没有静默改写调用方传参的"魔法"？
- [ ] 无界容器：全局 static / long-lived Vec/HashMap 是否有上限？
- [ ] 测试隔离：测试是否在全局单例上做增量断言？（该模式并行必 flaky）
- [ ] gen_range / 除法 / 索引：区间端点是否可能为 0/空？
