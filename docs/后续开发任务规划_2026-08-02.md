## 四、工程规范门禁（每次任务必须执行）

1. **门禁 1-4**：`cargo fmt --check` → `cargo check --workspace` → `cargo clippy --workspace --all-targets` → `cargo test`（受影响的 crate 全量）
2. **门禁 7**：差分 fuzz（`cargo test -p szrsql-sql --test sql_compare`，需本机 PG 18 运行）
3. **门禁 8**：无 todo!/unimplemented!/unreachable!（非测试代码）
4. **AI-1**：unsafe 必须有 `// SAFETY:` 注释
5. **AI-2**：生产代码无 unwrap/expect（测试代码除外）
6. **测试残留清理**：测试写盘的临时数据（`data/`、`*.log`、`tables.json` 等）完成后立即删除；`target/` 75GB 为构建缓存，必要时 `cargo clean`

## 五、测试注意

- **100M 级超长测试**（8 个）已全部 `#[ignore]`：columnar 2、read_ahead 1、spill 2、toast 1、btree_bench 1、其他 1——需显式 `-- --ignored` 才运行，日常回归不受影响
- **差分测试**需要本机 PostgreSQL 18（连接串见 AGENTS.md）
- **环境**：Windows 全 workspace 并行编译会内存不足（E0786），用 `-j 2` 限流
