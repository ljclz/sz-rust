## 二、缺失能力清单

### 2.1 完全缺失（🔴）

| 功能 | 影响 | 优先级 | 预估周期 |
|------|------|--------|----------|
| 并行查询执行器 | 大表扫描性能差 | P0 | 4-6 周 |
| CREATE EXTENSION | 无法加载 PostGIS/pgvector | P1 | 2-3 周 |
| CREATE RULE | 视图更新受限 | P2 | 1-2 周 |
| 表空间管理 | 无法多磁盘分布 | P2 | 1 周 |
| 多数据库支持 | 仅支持单库 | P1 | 2-3 周 |
| 复合类型 (CREATE TYPE AS) | 复杂数据模型受限 | P2 | 1-2 周 |
| pg_dump 工具 | 备份依赖代码导出 | P1 | 2-3 周 |
| HA 自动故障转移 | Raft 就绪但未启用 | P0 | 2-3 周 |

### 2.2 部分缺失（⚠️）

| 功能 | 当前状态 | 缺失内容 | 优先级 |
|------|----------|----------|--------|
| 存储引擎 | Vec\<Row\> 主存储 | 无真实分页/缓冲池 | P0 |
| WAL 写缓冲 | 有 append_batch | 无 Group Commit | P1 |
| 迭代器执行 | 已集成但未替换 | 仅 LIMIT 下推使用 | P1 |
| 驱动生态 | 无 JDBC/ODBC | 需开发驱动库 | P1 |
| 监控集成 | Prometheus 骨架 | 无真实指标暴露 | P2 |
