### 关键技术实现

**1. 多方言预处理转换**（`szrsql-sql/src/dialect.rs`）：
- MySQL：`LIMIT offset, count` → `LIMIT count OFFSET offset`、`ON DUPLICATE KEY UPDATE` → `ON CONFLICT DO UPDATE SET`、`MOD` 运算符 → `%`
- Oracle：`ROWNUM <= N` → `LIMIT N`、`DECODE` → `CASE`、`NVL` → `COALESCE`、`TO_DATE/TO_NUMBER/TO_CHAR` → `CAST`、`seq.NEXTVAL` → `nextval('seq')`、`SYSDATE` → `CURRENT_TIMESTAMP`、`MINUS` → `EXCEPT`
- SQL Server：`SELECT TOP N` → `LIMIT N`、`ISNULL` → `COALESCE`、`GETDATE/GETUTCDATE` → `CURRENT_TIMESTAMP`、`LEN` → `LENGTH`、`CONVERT` → `CAST`
- SQLite：`WITHOUT ROWID` → 移除、`PRAGMA` → `SELECT 1`、`GLOB/MATCH` → `LIKE`、`<<`/`>>` → `shift_left`/`shift_right` 函数调用

**2. 栈溢出防护（ADV-BUG-001 修复）**：
- SQL 长度预检：`MAX_SQL_LEN = 1MB`，超出直接拒绝
- OR/AND 链深度预检：`MAX_BINARY_OP_CHAIN = 32`，超出直接拒绝
- 表达式递归深度限制：`MAX_EXPR_DEPTH = 512`

**3. 对抗性测试栈溢出隔离**：
- `expect_no_panic` 函数在 64MB 大栈子线程中执行解析，避免栈溢出导致整个测试套件崩溃
- 子线程崩溃通过 `join()` 返回的 `Err` 检测，记为测试失败而非进程崩溃
