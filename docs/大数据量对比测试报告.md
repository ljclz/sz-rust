## 分析总结

### SzRSQL 性能定位

SzRSQL 是基于 Rust 的分布式 SQL 数据库，具备 WAL 预写日志 + B+Tree 持久化存储 + 崩溃恢复能力。
基准测试使用内存执行器（InMemoryTable）测量 SQL 引擎本身的计算性能，
不包含磁盘 I/O 开销，因此在读取操作上相比传统磁盘数据库具有天然优势。

### 结论

1. **SzRSQL 优势**: 内存执行器无 I/O 开销，SQL 引擎计算性能极佳，全数据规模下读写吞吐均领先
2. **SzRSQL 持久化**: 具备 WAL + B+Tree 持久化 + 崩溃恢复（此基准测试仅测量内存执行器性能）
3. **大数据量表现**: 1M/10M 行规模下，SzRSQL 全表扫描吞吐稳定在 2M+ rows/s，ORDER BY 因排序开销增加而下降
4. **适用场景**: 联机分析（OLAP）、缓存层、原型验证、嵌入式分析
5. **不适用场景**: 需要磁盘持久化的高并发在线事务（OLTP）—— 生产环境应启用 WAL 模式
