## 二、单项技能触发

### 1. 变异测试

| 操作 | 对话框输入 |
|------|-----------|
| 执行变异测试 | `执行 szrsql-mutation-testing 变异测试` |
| 指定文件变异 | `对 crates/szrsql-sql/src/parser.rs 执行变异测试` |

**命令行**（也可直接跑）：

```bash
cargo mutants --mutate "src/**/*.rs" --exclude "tests/**" --features "std" -- --test-threads=1
```

**先决条件**：

```bash
cargo install cargo-mutants
```

### 2. 差分模糊测试

| 操作 | 对话框输入 |
|------|-----------|
| 执行差分模糊测试 | `执行 szrsql-differential-fuzzing 与 PG 18 差分比对` |
| 指定运行时长 | `对 szrsql-sql crate 运行 6 小时模糊测试` |

**命令行**：

```bash
cargo fuzz run sql_compare -- -max_total_time=43200    # 12小时
cargo fuzz run sql_compare -- -max_total_time=21600    # 6小时
cargo fuzz run sql_compare -- -max_total_time=3600     # 1小时
```

### 3. 混沌工程

| 操作 | 对话框输入 |
|------|-----------|
| 执行混沌工程 | `执行 szrsql-chaos-engineering 并发死锁检测` |
| WAL 恢复测试 | `测试 WAL 断电恢复，模拟 kill -9 场景` |
| loom 并发穷举 | `对 BufferPool 和 BTree 运行 loom 并发测试` |
| 异步取消测试 | `测试客户端断线时事务回滚是否正确` |

**命令行**：

```bash
# loom 测试（需要 `--cfg loom` 或在 Cargo.toml 中 features）
cargo test --features loom --test chaos
```

## 三、日常快速验证

### 3.1 运行全部对抗性测试

**对话框输入**：

```
运行所有对抗性测试验证完整性
```

**命令行**（等价）：

```bash
cargo test --release -p szrsql-sql --test adversarial              # 44 个解析层测试
cargo test --release -p szrsql-sql --test adversarial_sql          # 44 个集成层测试
cargo test --release -p szrsql-tx --test adversarial_tx            # 27 个事务层测试
cargo test --release -p szrsql-protocol --test adversarial_net     # 26 个协议层测试
```

### 3.2 运行全部单元测试

**对话框输入**：

```
运行全部测试，确认无回归
```

**命令行**：

```bash
cargo test --workspace --release
```

### 3.3 运行特定 crate 测试

```bash
cargo test --release -p szrsql-sql     # SQL 层
cargo test --release -p szrsql-tx      # 事务层
cargo test --release -p szrsql-storage # 存储层
cargo test --release -p szrsql-protocol# 协议层
```

### 4.3 铁律自检清单（AI 每次修改前检查）

- [ ] 是否读取了 `.trae/rules/project_rules.md`？
