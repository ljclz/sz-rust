### 1.2 架构概览

```
szrsql-bin          → 二进制入口（pgwire 服务、HTTP 管理、信号处理）
szrsql-protocol     → pgwire 协议实现（认证、连接管理、守护进程化）
szrsql-sql          → SQL 解析器、执行器（DML/DDL/DCL、JOIN、聚合、窗口函数）
szrsql-optimizer    → 查询优化器（CBO/RBO、CSE、谓词下推、Join 重排）
szrsql-storage      → 存储引擎（B+Tree 持久化、BufferPool 刷盘、列式存储、TOAST、远程FS、Spill）
szrsql-tx           → 事务管理（MVCC、WAL fsync、锁管理、崩溃恢复、Vacuum、WAL压缩/FPI/Summarizer）
szrsql-dist         → 分布式组件（Raft 共识、分片、Percolator 事务）
szrsql-types        → 类型系统（Value、ColumnType、Schema）
szrsql-pgcompat     → PostgreSQL 兼容性测试
szrsql-security     → 安全模块（TDE、审计、防火墙、SQLi 检测、脱敏）
szrsql-replication  → 复制模块（流复制、逻辑复制、DR、备份恢复）
szrsql-scheduler    → 调度器
szrsql-ops          → 运维模块（指标、告警、慢查询、ASH、pprof）
szrsql-ai           → AI 向量检索（SIMD 加速）
```

> **持久化能力说明**：项目具备完整的持久化实现：
> - **WAL 预写日志**：`szrsql-tx/src/wal.rs` 提供 `WalWriter::flush()` 强制 fsync 刷盘、`WalReader` 崩溃恢复、`WalRecord` CRC32C 校验
> - **B+Tree 持久化**：`szrsql-storage/src/buffer.rs` 通过 `InMemoryPageWriter` 提供 Page 持久化接口（注释明确"write_page 完成后数据已持久化（fsync 或等价语义）"）
> - **远程存储**：`szrsql-storage/src/remote_fs.rs` 支持 S3 / HTTP 后端
> - **溢写盘**：`szrsql-storage/src/spill.rs` 支持大结果集落盘
> - **备份恢复**：`szrsql-replication/src/backup.rs` (104KB) 提供完整备份恢复
> - **WAL 增强**：`wal_compression.rs` / `wal_fpi.rs` / `wal_summarizer.rs` 提供压缩、全页镜像、WAL 摘要
> - **崩溃恢复测试**：6 类崩溃恢复测试 + fuzz 验证
